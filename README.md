## 🏔️ Currently building

### [PeakProfile](https://github.com/gertaxhepi/peakprofile-climb-smart) · 2025–Present

An AI-assisted platform that helps mountaineers and mountain guides plan better-matched expeditions across the Alps.

I’m exploring how structured climbing experience, route requirements, deterministic safety rules, and AI-generated explanations can support more informed decisions—while keeping final responsibility with the climber and guide.

**Current focus:**

- Mountaineer profiles and climbing history
- Expedition publishing for mountain guides
- Explainable readiness assessments
- AI-assisted communication for guide communities
